# CLP-CCM Example Run 01 — Authority Overlap

## Scenario
Multiple actors claim authority over the same decision gate.

## Observed Pattern
- Screening authority asserted by more than one actor
- No shared threshold or rationale
- Decisions appear inconsistent externally

## Output (Descriptive)
- Coordination friction increases
- Duplicate checks emerge
- End-user explanations diverge

## Notes
This example does not imply error, fault, or remedy.
It illustrates structural overlap only.
