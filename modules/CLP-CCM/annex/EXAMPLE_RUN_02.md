# CLP-CCM Example Run 02 — Circular Accountability

## Scenario
Resolution requires information held by another actor who cannot or will not provide it.

## Observed Pattern
- Each actor defers responsibility
- Requests loop without terminal resolution
- No actor can unilaterally close the issue

## Output (Descriptive)
- Repair loops
- Latency amplification
- Perceived system paralysis

## Notes
This example demonstrates coordination failure without assigning blame.
